# Календарь звонков

Одновладельческий календарь для записи на звонки: посетитель выбирает свободный слот и оставляет имя с электронной почтой, а владелец видит предстоящие события.

## Language

**Calendar owner**:
Единственный владелец календаря, чьё время занимают записи; окно бронирования задаётся в его часовом поясе.
_Avoid_: user, host, manager, аккаунт

**Slot**:
Фиксированный 30-минутный интервал внутри ежедневного окна календаря с 09:00 до 18:00; минимальная единица, которую бронирует посетитель. В дне их ровно 18.
_Avoid_: timeslot, time slot, appointment, ячейка, окно

**Slot status**:
Признак слота «Свободно» или «Занято»: занят, если у слота есть бронь или слот уже в прошлом; иначе свободен.
_Avoid_: state, availability flag

**Booking**:
Бронь одного Slot посетителем; состоит из имени, электронной почты, начала слота и момента создания. На один Slot приходится не более одной брони.
_Avoid_: event, appointment, reservation, запись, встреча

**Booking window**:
Отрезок календаря, доступный для брони: от сегодняшнего дня до сегодня + 60 дней. Дни за его пределами не бронируются.
_Avoid_: horizon, range

**Upcoming event**:
Отображение Booking в разделе «Предстоящие события»; показываются только брони с началом в будущем, по возрастанию времени.
_Avoid_: event, запись
